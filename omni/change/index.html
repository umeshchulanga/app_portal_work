Manual Rules Implemented

These are the rules that can be read directly from the attached worked example.

Core formula

This version calculates by actual calendar dates. It uses annual rate × new-bus seat count × chargeable days ÷ 365, treating 12 months as 365 days. Start and end dates are counted inclusively.

Late penalty

The example applies a 10% penalty because the licence was obtained more than 7 days after the new bus's first-registration/start date. This calculator applies the penalty only to the overlap/arrears portion, matching the example.

30-day manual check

The source page also refers to a 30-day condition. Because the wording is procedural rather than a clearly shown arithmetic formula, this app does not invent an extra charge. Instead, it displays a manual-review warning when the remaining overlap is under 30 days.

Important arithmetic note

The photographed example calculates in whole months. This updated calculator intentionally uses exact date ranges with a 365-day annual basis, so the result can differ from the printed monthly example.
